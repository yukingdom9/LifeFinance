# 資産形成・老後資金シミュレーション

積立投資 → 定率取崩 → 年金受給の3つのシミュレーションをひとつなぎにして、
**老後に毎月いくら使えるのか** を一気通貫で確認できる静的サイトです。
ビルド不要、`index.html` をブラウザで開くだけで動作します。

## 構成ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページ構造（Stage1〜4 のマークアップ） |
| `style.css` | 見た目（配色・レイアウト・レスポンシブ対応） |
| `script.js` | 各シミュレーションの計算ロジックと描画、Stage間の連携 |

外部ライブラリへの依存はなく、`<svg>` と `<canvas>` を素の JavaScript で描画しています。

## 画面構成（Stage 1〜4）

### Stage 1: 積立投資フェーズ
元本・積立（月額）・年利率・運用期間を入力すると、複利で運用した場合の資産推移を折れ線グラフで表示します。

- 最終残高 / 総投資額 / 運用益 を算出
- 月次複利: `残高 = 残高 × (1 + 年利率/12) + 積立額`

### コネクター（Stage1 → Stage2）
トグルをONにすると、Stage1の「最終残高」がそのままStage2の「元本」として連携されます（OFFにすると手動入力に切替）。

### Stage 2: 定率取崩フェーズ
元本・年利率・取崩率を入力すると、資産を毎月一定割合ずつ取り崩した場合の「毎月の取崩額」と資産残高の推移（40年間）を表示します。

- 毎月の取崩額 = `残高 × (取崩率/12)`
- 取崩後、残りの残高にも運用利回りが複利で乗ります
- 初回 / 20年後 / 40年後の取崩額と最終残高を表示

### Stage 3: 年金受給フェーズ
平均年収・国民年金/厚生年金の加入年数・受給開始年齢（①②の2パターン）・運用利回りを入力すると、年齢ごとの月額受給額と、①②それぞれを年金開始から運用に回した場合の損益分岐点年齢をグラフで表示します。

- 国民年金: `65,000円 × (国民年金加入年数 / 40)`
- 厚生年金: `平均年収 / 12 × 0.0056 × 厚生年金加入年数`
- 65歳からの繰上げ/繰下げ補正: 65歳超は `+0.084/年`、65歳未満は `+0.048/年`

### Stage 4: 統合結果
Stage2の「毎月の取崩額」と、Stage3の「開始年齢②」の月額受給額を合計し、
**「老後、毎月使えるお金」** として表示します。すべての入力値変更にリアルタイムで追従します。

```
老後、毎月使えるお金 = Stage2の毎月の取崩額 + Stage3の年金月額（開始年齢②）
```

## 共有リンク

画面下部の「共有リンクをコピー」ボタンで、現在の全入力値（Stage1〜3すべて）をURLクエリパラメータに埋め込んだリンクをクリップボードにコピーできます。そのURLを開くと同じ入力状態が再現されます。

## ローカルでの確認方法

`index.html` をブラウザで直接開くだけで動作します。開発サーバーが必要な場合は任意の静的サーバーで配信してください。

```bash
# 例: Node.js があれば
npx serve .

# 例: Python があれば
python -m http.server 8000
```

## 由来

このサイトは以下2つの既存シミュレーターを統合したものです。

- `investment_withdrawal_p`（積立投資 & 定率取崩シミュレーション） … Stage 1・2
- `PensionCalculator`（年金受給シミュレーション） … Stage 3

Stage 4（統合結果）は、上記2つの結果を組み合わせるためにこのプロジェクトで新規追加しました。
